# IPT-FINALPROJECT-CRFD

**Project Title:** Cooking Recipes (For Disaster) — CRFD  
**Author:** Jessieca Mae D. Milan  
**Website Category:** Recipe Website / Entertainment

## Project Description

CRFD is a recipe content platform for browsing Filipino recipes and their variations. Dedicated to my little sister, its simple design and functionality is built to make following cooking instructions as easy as can be.

## Main Features

1. **Browse Recipes** — View recipe cards on the homepage and filter them by meal type (Breakfast, Lunch, Dinner, Dessert) and protein type (Chicken, Pork, Fish, Beef, Other)
2. **Explore Variations** — Each recipe includes a Variations tab showing alternative cooking methods, added ingredients, or substitutions for the same dish
3. **Search Recipes** — Search for specific dishes using the search bar on the homepage; search works in combination with the category filters
4. **Submit Recipes** — Users can submit their own recipes through a public submission form
5. **Admin Review** — Admins can log in to view, approve, or reject pending submissions before they appear on the site
